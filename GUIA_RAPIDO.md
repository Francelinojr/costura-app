# 🚀 Guia Rápido - Costura Fácil

## Como Começar

### 1. Adicionar sua Primeira Cliente
1. Abra o app e vá para a aba **"Clientes"**
2. Clique no botão **"+"** (flutuante)
3. Preencha os dados:
   - **Nome** (obrigatório)
   - Telefone
   - Email
   - Escola/Instituição
   - Observações
4. Adicione as **medidas** (em cm):
   - Busto
   - Cintura
   - Quadril
   - Manga
   - Comprimento Blusa
   - Comprimento Calça
   - Ombro
   - Pescoço
5. Clique em **"Salvar"**

### 2. Criar um Novo Pedido
1. Vá para a aba **"Pedidos"**
2. Clique no botão **"+"**
3. Selecione a **cliente**
4. Preencha:
   - Tipo de peça (Blusa, Calça, Saia, etc.)
   - Descrição do pedido
   - Valor (opcional)
   - Status (Orçamento, Confirmado, etc.)
   - Data de prazo
   - Observações
5. Clique em **"Salvar"**

### 3. Fazer um Orçamento
1. Vá para a aba **"Orçamentos"**
2. Clique no botão **"+"**
3. Selecione a **cliente**
4. Preencha os valores:
   - Mão de obra
   - Tecido
   - Acabamento
   - Desconto (opcional)
5. O **total** é calculado automaticamente
6. Defina a **data de validade**
7. Marque como "Aceito" quando o cliente aceitar
8. Clique em **"Salvar"**

### 4. Adicionar Trabalho ao Portfólio
1. Vá para a aba **"Portfólio"**
2. Clique no botão **"+"**
3. Selecione ou tire uma **foto** do trabalho
4. Preencha:
   - Título do trabalho
   - Tipo de peça
   - Descrição
   - Cliente (opcional)
   - Avaliação (0-5 estrelas)
5. Clique em **"Salvar"**

## 📊 Dashboard (Tela Inicial)

Na tela inicial você vê:
- **Total de clientes** cadastradas
- **Total de pedidos** em aberto
- **Total de orçamentos**
- **Total de trabalhos** no portfólio
- **Pedidos em atraso** (com aviso em vermelho)
- **Próximos pedidos** a entregar (próximos 7 dias)

## 🔍 Buscas e Filtros

### Buscar Clientes
- Na aba "Clientes", use a barra de busca
- Busca por: nome, telefone ou escola

### Filtrar Pedidos
- Na aba "Pedidos", use os filtros:
  - Todos
  - Orçamento
  - Confirmado
  - Em Progresso
  - Pronto
  - Entregue

### Filtrar Orçamentos
- Na aba "Orçamentos", use os filtros:
  - Todos
  - Pendentes
  - Aceitos

### Filtrar Portfólio
- Na aba "Portfólio", use os filtros por tipo de peça

## ✏️ Editar Dados

### Editar Cliente
1. Vá para "Clientes"
2. Clique na cliente desejada
3. Clique no menu (3 pontos) → "Editar"
4. Faça as alterações
5. Clique em "Salvar"

### Editar Pedido
1. Vá para "Pedidos"
2. Clique no botão "Editar" do pedido
3. Faça as alterações
4. Clique em "Salvar"

### Editar Orçamento
1. Vá para "Orçamentos"
2. Clique no botão "Editar"
3. Faça as alterações
4. Clique em "Salvar"

## 🗑️ Deletar Dados

1. Clique no botão "Deletar" ou no menu de opções
2. Confirme a exclusão
3. O dado será removido permanentemente

⚠️ **Aviso**: Deletar é irreversível!

## 💡 Dicas Úteis

### Status de Pedidos
- **Orçamento**: Ainda não confirmado
- **Confirmado**: Cliente aceitou
- **Em Progresso**: Você está costurando
- **Pronto**: Peça pronta, aguardando entrega
- **Entregue**: Entregue ao cliente
- **Cancelado**: Pedido cancelado

### Alertas Automáticos
- ⚠️ **Pedidos em atraso** aparecem em vermelho no dashboard
- 📅 **Próximos pedidos** aparecem em verde (próximos 7 dias)

### Cálculo de Orçamento
```
Total = Mão de obra + Tecido + Acabamento - Desconto
```

## ❓ Perguntas Frequentes

**P: Posso usar em múltiplos dispositivos?**
R: Não. Os dados são locais. Para usar em outro dispositivo, você precisará fazer backup e restaurar.

**P: Como faço backup dos dados?**
R: Use as ferramentas nativas do seu dispositivo (Android: Google Drive, iOS: iCloud).

**P: Posso compartilhar meu portfólio?**
R: Atualmente não. Sugestão para versão futura!

**P: Os dados são sincronizados com nuvem?**
R: Não. Tudo fica local no seu dispositivo.

**P: Posso deletar um cliente e manter seus pedidos?**
R: Não. Deletar um cliente remove todos os dados associados.
